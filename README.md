## Selected projects

### 🧠 [MI300X AI Infra Kit](https://github.com/midildar/minimal_full_stack_boilerplate_for_private_RAG)

A full-stack starting point for private, retrieval-augmented AI applications. Combines **Next.js, FastAPI, PostgreSQL, Qdrant, and Docker Compose** with document ingestion, embeddings, vector search, and source-backed chat. Designed around OpenAI-compatible model endpoints, with GPU-backed serving as a future direction.

### 💬 [GapShap](https://github.com/midildar/gapshap) · [Frontend](https://github.com/midildar/gapshap_front)

A real-time chat application built with **React, Node.js, Express, Socket.IO, MongoDB, and Redis**. A practical project for working across client/server boundaries, real-time communication, and containerized services.

### 🛡️ [Sybil Attack Detection Web App](https://github.com/midildar/Sybil-Attack-detection-Web-App)

A Python-based web application focused on Sybil-attack detection, bringing together application development and security-oriented experimentation.

## Open-source investigation

I reported and investigated an **OpenNext / Next.js 16 cache-interception bug** that caused unbounded segment-prefetch requests. I documented a reproducible case, isolated the underlying behavior, and later **verified the upstream fix locally and on Cloudflare Workers**.

**[Read the issue, root-cause analysis, and verification →](https://github.com/opennextjs/opennextjs-aws/issues/1212)**
